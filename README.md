# Syrian Symposium 2027

A professional, responsive website developed for the **Syrian Symposium 2027**, a one-day conference taking place on **30 January 2027 at King's College London**.

**Live Website:** [Visit Syrian Symposium 2027](https://syriansymposium.netlify.app/)

The symposium aims to connect Syrian professionals, academics and young people, inspiring the next generation to contribute to Syria's future through knowledge-sharing, collaboration and networking.

## Website Purpose

The website serves as the symposium's central digital platform, designed to:

- Promote the event and facilitate ticket sales.
- Showcase speakers, panel discussions and the conference schedule.
- Provide sponsorship and collaboration opportunities through the **Join Us** page.
- Highlight previous events and community initiatives.
- Provide accessible event information and contact opportunities.

## Tech Stack

- **Frontend:** React, JavaScript, Vite, HTML, CSS
- **CMS:** Sanity (GROQ queries)
- **Routing:** React Router
- **Animations:** Intersection Observer API, CSS transitions

## Key Features

- Fully responsive design across desktop, tablet and mobile.
- Dynamic content management through Sanity CMS, allowing organisers to update event information without code changes.
- Interactive speaker profiles, event schedules and past-event slideshows.
- Scroll-triggered animations and continuous partner-logo marquees.
- Dedicated sponsorship page with access to sponsorship materials and collaboration enquiries.

## Event Details

**Date:** 30 January 2027  
**Location:** King's College London, UK  
**Format:** Talks, panel discussions and networking opportunities
